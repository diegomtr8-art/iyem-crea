## CONVENCIONES DEL PROYECTO (respetar siempre)
- PHPDoc en todos los métodos públicos nuevos
- FormRequest para validaciones complejas (no inline en el controlador)
- Tipos TypeScript en el front (props tipados, no usar `any` salvo necesidad)
- Tailwind CSS para estilos (no CSS inline en Vue salvo dompdf)
- Inertia::render() siempre retorna el componente Vue correcto
- Respuestas JSON del backend: siempre `{ ok: true, ... }` o `{ error: '...' }`
- Transacciones DB::transaction() para operaciones que modifican múltiples tablas
- Auth::id() para registrar quién hizo la acción en auditoría
- Carbon con timezone 'America/Merida' para fechas

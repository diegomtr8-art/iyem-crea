# PROMPT — RESPONSIVE MOBILE: iPhone & iPad
# Proyecto CREA · Laravel 11 + Vue 3 + Inertia.js + Tailwind CSS
# Breakpoints Tailwind usados: (default=mobile) sm:640px md:768px lg:1024px xl:1280px
# ─────────────────────────────────────────────────────────────────────────────────

## OBJETIVO
Hacer que TODO el sistema CREA funcione perfectamente en:
- iPhone SE / 12 / 14 / 15 (375–430px)
- iPad / iPad Pro (768–1024px)
Sin romper el layout de escritorio (≥1024px) que ya funciona.

Principio: **mobile-first**. Las clases base son para móvil. md: y lg: sobrescriben hacia arriba.

## REGLAS GLOBALES (aplicar en TODOS los archivos)
1. Toda `<table>` debe estar envuelta en `<div class="overflow-x-auto">` si no lo está ya.
2. Cualquier `grid-cols-N` sin prefijo responsive → agregar `grid-cols-1 sm:grid-cols-N` o el que corresponda.
3. `grid-cols-12` → en mobile usar `grid-cols-1`, en lg mantener `grid-cols-12`.
4. Anchos fijos `w-80`, `w-96` en paneles flotantes → `w-[calc(100vw-2rem)] max-w-sm` en mobile.
5. Padding lateral: `px-4 sm:px-6` en contenedores padre (no más `px-6` sin prefijo en mobile).
6. `max-w-7xl mx-auto` es correcto, solo verificar que siempre tenga `px-4`.
7. Botones en fila en mobile → `flex flex-col sm:flex-row` o `flex flex-wrap`.
8. Inputs side-by-side sin `sm:` → `grid-cols-1 sm:grid-cols-2`.
9. Texto truncado: añadir `truncate` o `break-words` donde el texto largo rompe el layout.
10. Sticky header/nav: ya existe, verificar `z-index` correcto (z-40 nav, z-50 dropdowns).

## PATRÓN: TABLA → CARDS EN MOBILE (para tablas de más de 5 columnas)
## ─────────────────────────────────────────────────────────────────

Para tablas con muchas columnas que son difíciles de leer en mobile aunque hagan scroll,
usar el patrón de "card list" en mobile:

```vue
<!-- Tabla solo en sm+ -->
<div class="hidden sm:block overflow-x-auto">
  <table class="w-full min-w-[600px] ...">
    ...
  </table>
</div>

<!-- Cards en mobile -->
<div class="sm:hidden space-y-3">
  <div v-for="item in items" :key="item.id"
    class="bg-white dark:bg-zinc-900 rounded-2xl border border-zinc-100 dark:border-zinc-800 p-4">
    <div class="flex items-center justify-between mb-2">
      <p class="font-bold text-sm">{{ item.nombre }}</p>
      <span class="badge ...">{{ item.estatus }}</span>
    </div>
    <div class="grid grid-cols-2 gap-2 text-xs text-zinc-500">
      <div><span class="font-medium">Monto:</span> {{ fmt(item.monto) }}</div>
      <div><span class="font-medium">Modalidad:</span> {{ item.modalidad }}</div>
      <div><span class="font-medium">Municipio:</span> {{ item.municipio }}</div>
      <div><span class="font-medium">Fecha:</span> {{ item.fecha }}</div>
    </div>
    <div class="mt-3 flex gap-2">
      <Link :href="route('...', item.id)" class="flex-1 text-center py-2 bg-slate-100 dark:bg-zinc-800 rounded-xl text-xs font-bold">
        Ver detalle
      </Link>
    </div>
  </div>
</div>
```

**Aplicar este patrón cards/tabla en:**
- Solicitudes/Index.vue → cards en mobile
- Acreditados/Index.vue → cards en mobile
- Cobranza/Index.vue → cards en mobile
- Comprobaciones/Index.vue → cards en mobile (construir mobile-first)
